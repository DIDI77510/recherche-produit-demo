# Recherche Produit

Dépôt de test pour s'entraîner au workflow GitHub : branches, commits et pull requests.

## Démarrage

1. Clonez le dépôt : `git clone https://github.com/DIDI77510/recherche-produit-demo.git`
2. Créez une branche pour vos changements : `git checkout -b ma-branche`
3. Ouvrez une pull request une fois vos changements poussés.
