# Promo produits numériques Marie Virgile

- `posts/<AAAA-MM-JJ>-<HHMM>-<produit>/content.json` : textes des slides.
- `python3 build.py posts/<dossier>/content.json` : carrousel `slide-N.jpg` (1080×1350) ; si `"video": true`, `video.mp4` (1080×1920, ~10-13 s) + `cover.jpg`.
- Les rendus de pages produit (PNG pleine résolution) ne sont **pas** dans le dépôt (ils resteraient téléchargeables gratuitement) : `PAGES_DIR` pointe vers un dossier local.
- URL publiques : `https://raw.githubusercontent.com/DIDI77510/recherche-produit-demo/main/produits-numeriques/posts/<dossier>/<fichier>`
